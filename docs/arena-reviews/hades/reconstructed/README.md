# reconstructed/ — what this is, and what it is not

## It is

A **freshly written** test harness for four areas of the CLASH settlement engine:

1. cancelled-settlement invariant and the settled-ledger contract, per reward schema (`tests/01`)
2. fighter-reward accounting against an independent reference calculator (`tests/02`)
3. concurrent settlement under 2–8 simultaneous workers (`tests/03`)
4. Clash → Room lock-order analysis, static and dynamic (`tests/04`)

Every result in `logs/` was produced by these scripts, on PostgreSQL 16.2, while
preparing this package.

## It is not

- a copy of the original review harness — that was lost with the sandbox and was
  never committed, so no copy exists;
- a reproduction of any historical log, result, manifest or report;
- a full reproduction of the original review's scope. Only the four prioritised
  areas are covered. Mutation testing, seeded replay, and the wider security
  composition probes from the original review are **not** included here.

No historical result is claimed anywhere in this tree. If a number appears in a
log, that log was generated by the adjacent script.

## Design notes

**Assertions are on totals, not row presence.** A settlement that pays a juror three
times creates the same *kinds* of rows as one that pays correctly; only the summed
`reputation_delta` and `coins_delta` reveal the difference. Several tests therefore
compare the full ledger multiset against a reference calculator implemented
separately from the SQL.

**Fixtures are fictional and isolated.** Every user, take and clash is generated per
run with a random suffix. Nothing reads from or writes to a real system.

**The loader destroys schemas.** `loader.mjs` drops and recreates `public`, `auth`,
`storage`, `realtime` and `extensions`. It is for disposable instances only.

## Running

```bash
node run-all.mjs --migrations=<baseline-dir> --patched=<baseline+patch-dir>
```

Exits `0` when all suites pass, `1` on a failing suite, `2` on a setup problem
(missing migration directory, contaminated schema).

## Interpreting exit codes

| Test | exit 0 means |
|---|---|
| `01`, `02`, `03`, `04` | all assertions passed |

## Withheld material

A stricter adversarial variant of the cancelled-settlement test, and its captured
output, are held in the **private review record** and are not part of this package.
They encode a reproduction recipe for an issue that is not yet fixed, so publishing
them would not be appropriate. The public tests here verify the same intended
invariant from the outside, without that recipe. This omission is intentional and is
the reason the public suite is not a complete reproduction of the full review.
